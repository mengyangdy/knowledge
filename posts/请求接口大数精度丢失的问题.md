在使用uni.request请求接口的时候，后端返回了一个19位的数字类型的id，后端返回的是1067722413883658240，但是打印出来的就是1067722413883658200，原因就是精度丢失的问题

## 解决思路

1. 让后端返回数据时把number类型改为string类型
2. uni.request里面有个参数是`dataType`默认值为`json`，(如果设为 json，会对返回的数据进行一次 JSON.parse，非 json 不会进行 JSON.parse),我们可以先将`dataType`设置为`string`,然后进行正则转换即可

```js
const data={
  id:1067722413883658240,
  userId:1067722413883658241,
  name:"111",
  logo:'222',
  type:1
}

let endData=JSON.stringify(data)
const json=endData.replace(/:s*([0-9]{15,})s*(,?)/g, ': "$1" $2')

const transData=JSON.parse(json)

console.log(data);
console.log(transData);

/**
 * {
  id: 1067722413883658200,
  userId: 1067722413883658200,
  name: '111',
  logo: '222',
  type: 1
}
{
  id: '1067722413883658200',
  userId: '1067722413883658200',
  name: '111',
  logo: '222',
  type: 1
}
 */
```

3. 使用第三方的包`json-bigint`处理接口返回的数据

```js
import JSONbig from 'json-bigint'

const data={
  id:1067722413883658240,
  userId:1067722413883658241,
  name:"111",
  logo:'222',
  type:1
}

const endData=JSON.stringify(data)

const transData=JSONbig({storeAsString : true}).parse(endData)
console.log("🚀 ~ transData:", transData)

/**
 * 
id: "1067722413883658200",
logo: "222",
name: "111",
type: 1,
userId: "1067722413883658200"
 */
```

4. 如果是在`axios`中使用的话，可以配置一下`transformResponse`这个函数然后进行转化就可以了
